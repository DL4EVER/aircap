# 耳机音量上限 (EarVolumeCap)

一个极简的安卓小工具：**给蓝牙耳机设一个人为的音量上限**。
比如上限设为 40%，之后无论怎么按音量+（手机上按、耳机上按都算），媒体音量都不会超过 40%。

背景：骑车风噪大，误触音量+会把 TWS 耳机拉到满音量炸耳朵。这个应用就是那个"上限"。

## 工作原理

现代蓝牙耳机连接安卓时走 **AVRCP 绝对音量**：手机媒体流音量 == 耳机内部音量，两者实时同步。
所以钳住手机侧的媒体流，就等于钳住了耳机实际输出的响度，不需要 root。

两层机制（v0.2 起：无障碍服务是主载体，前台服务可选）：

| 层 | 组件 | 管什么 |
|---|---|---|
| 主 | `VolumeKeyAccessibilityService` 无障碍服务 | 拦截手机侧**音量+按键**（到上限后按了没反应）；同时承载钳制逻辑（ContentObserver + 2 秒兜底轮询），覆盖**耳机上**按的音量键。系统托管，被杀自动重绑，无常驻通知、无需锁定后台 |
| 备 | `VolumeClampService` 前台服务（可选，默认关） | 同样的钳制逻辑，双保险 |

生效条件：开关已启用 **且** 检测到蓝牙音频设备（A2DP / LE Audio）。外放不受影响。

## 安装（手机上）

1. 打开仓库的 **Releases** 页面 → `app-latest` → 下载最新的 `EarCap-build-*.apk`
2. 安装（需允许"安装未知应用"）
3. 打开应用，按顺序做三件事：
   - 允许通知权限（弹窗同意即可）
   - 点「申请电池优化白名单」，选允许
   - 点「无障碍设置」，在系统无障碍列表里找到"耳机音量上限"并开启
4. 回到应用，打开「启用音量上限」开关，滑条设置上限（建议 40% 左右）

## ColorOS / OriginOS 额外设置（重要）

国产 ROM 杀后台很凶，要让服务活下来：

- 设置 → 电池 → 找到本应用 → 允许后台运行 / 关闭"应用速冻"
- 最近任务界面，把本应用卡片下拉（或长按）→ 锁定
- 设置 → 应用管理 → 本应用 → 允许自启动

## 验证方法

1. 连上 TWS 耳机，放首歌
2. 连按音量+：到上限后，手机按键无反应（无障碍层）；耳机按键音量不再上涨（钳制层）
3. 断开耳机用外放：音量不受限制

## 已知边界

- 个别耳机固件是纯本地调音量（不经过手机 AVRCP），手机侧管不住——主流 TWS 没这个问题
- 开发者选项里开启「停用绝对音量」会失效
- 没开无障碍时，手机音量+到上限会"跳上去被弹回"（服务层兜底），体验稍差但同样安全

## 云构建

推送代码到 `main` 分支 → GitHub Actions 自动编译 → APK 自动发布到 Releases（tag `app-latest` 始终是最新版）。
本地不需要安装任何开发环境。
